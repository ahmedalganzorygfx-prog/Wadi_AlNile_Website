# موقع مطاعم أسماك وادي النيل

موقع تعريفي عربي متجاوب، مستقل عن Streamlit، مبني باستخدام HTML وCSS وJavaScript دون الحاجة إلى تثبيت Python أو قاعدة بيانات.

## محتويات المشروع
- `index.html` — الصفحة الرئيسية.
- `menu.html` — قائمة الطعام والتصنيفات.
- `about.html` — عن المطعم والقيم.
- `branches.html` — صفحة الفروع.
- `contact.html` — نموذج تواصل تجريبي.
- `assets/style.css` — الهوية البصرية والتصميم المتجاوب.
- `assets/script.js` — قائمة الهاتف، السنة الحالية، وتجهيز رسالة التواصل.
- `assets/brand-preview.png` — مرجع بصري للتصميم المقترح (إن توفر).

## التشغيل محليًا
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو Edge.
3. يتطلب تحميل الصور والخط الخارجي اتصالًا بالإنترنت.

يمكن رفع المجلد نفسه إلى استضافة مواقع ثابتة تدعم HTML مثل GitHub Pages أو Netlify أو أي استضافة تقليدية.

## تنبيهات قبل النشر
- أسماء الفروع المعروضة أمثلة أولية، والعناوين وأرقام الهواتف تحتاج إلى اعتماد رسمي.
- أصناف المنيو وصفية وليست قائمة أسعار نهائية؛ الأسعار لم تُخترع.
- روابط الشبكات الاجتماعية تحتاج إلى استبدالها بالروابط الرسمية.
- نموذج التواصل لا يرسل البيانات إلى خادم في هذه النسخة؛ يحتاج إلى ربط بخدمة بريد/نموذج أو Backend لاستقبال الرسائل.
- الصور الحالية من روابط Unsplash، ويجب استبدالها بصور المطعم الحقيقية عند توافرها.
- لا يحتوي هذا المشروع على بيانات أو قاعدة بيانات قديمة، لأنه مشروع جديد بالكامل. لم يتم حذف أو تعديل أي بيانات من المشروع السابق.


## تغيير الشعار لاحقًا
الشعار الحالي ملف SVG جاهز داخل `assets/logo.svg` ويظهر تلقائيًا في رأس الصفحات وتذييلها. لتغيير الشعار إلى شعار المطعم الأصلي، استبدل محتوى `assets/logo.svg` بملف SVG الخاص بك مع الاحتفاظ بالاسم والمسار، أو حوّل صورة PNG إلى `assets/logo.png` ثم غيّر `src="assets/logo.svg"` إلى `src="assets/logo.png"` في ملفات HTML الخمسة.
